06 — Components

UI Patterns

Buttons

  • Primary: Blue bg (#4db8ff), navy text, 14px bold, 4px radius, 14px 32px padding
  • Secondary: Blue text with bottom border only, no background
  • Ghost: Transparent with subtle border, white text

Cards

  • Navy background (#0d1b2a), subtle gray-dim borders
  • Hover: slightly darker + scale(1.02), smooth transition
  • Work cards: 16:9 image with dark gradient overlay at bottom, tag chips, title beneath

Navigation

  • Fixed header with gradient + backdrop blur (blur 8px)
  • Logo: "Josh Soliz" — Archivo 18px 600 weight
  • CTA in nav: blue border button, 4px radius
  • Background opacity increases after 60px scroll

Section Labels

  • 11px, Archivo 600, letter-spacing 0.18em, uppercase, blue accent color
  • Always appears above section heading with 24px margin-bottom

07 — Motion

Animation & Transitions

  • Fade-up on load: 0.8s ease, staggered delays (0.2s → 1.0s) for hero elements
  • Scroll-triggered reveals via Intersection Observer
  • Hover transitions: color, opacity, scale — always smooth (0.3s ease)
  • Smooth scrolling enabled site-wide
  • No abrupt or jarring animations — everything intentional and restrained
